Chaldean vs Pythagorean Numerology: What's the Difference?

Two main schools of numerology (Chaldean and Pythagorean) don't always agree. Chaldean numerology assigns values based on the sound and feel of the letter; it's the older of the two. Pythagorean numerology just uses a letter's position in the alphabet. This free name numerology checker uses the Chaldean method, so if you've got a number elsewhere using the other system, don't be surprised if it doesn't match. That's just how it is - not a mistake.
